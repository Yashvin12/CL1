3. THEORETICAL BACKGROUND
--------------------------------------------------------------------------------
3.1 REGRESSION ANALYSIS
Regression Analysis is a supervised machine learning technique used to model
the relationship between a continuous dependent variable (target) and one or more
independent variables (features).

It is used to:
- Predict numerical values (price, temperature, sales, fare)
- Quantify the impact of each feature on the output
- Understand relationships and trends in data

Types of Regression and their use cases:
---------------------------------------------------------------------------
 Type                     When to Use
---------------------------------------------------------------------------
 Linear Regression        Linear relationship between variables
 Multiple Regression      More than one independent variable
 Polynomial Regression    Non-linear but can be modeled by powers of X
 Ridge Regression         Regularization to prevent overfitting (L2 penalty)
 Lasso Regression         Regularization + feature selection (L1 penalty)
 Logistic Regression      Binary classification (not for continuous output)
---------------------------------------------------------------------------


3.2 LINEAR REGRESSION
Linear Regression models the relationship between target y and features X as:

    y = β0 + β1*x1 + β2*x2 + ... + βn*xn + ε

Where:
    y     = Predicted target (fare_amount)
    β0    = Intercept (bias term)
    β1..n = Coefficients (weights) for each feature
    ε     = Error term (residual)

The model minimizes the Residual Sum of Squares (RSS):
    RSS = Σ(y_actual - y_predicted)²

The solution for β using Ordinary Least Squares (OLS):
    β = (Xᵀ * X)⁻¹ * Xᵀ * y


3.3 RIDGE REGRESSION (L2 Regularization)
Ridge Regression adds a regularization term (L2 penalty) to the cost function
to prevent overfitting by shrinking coefficients toward zero:

    Cost = RSS + α * Σ(βj²)

Where α (alpha) is the regularization strength:
    - α = 0  →  Same as Linear Regression
    - High α →  Coefficients shrink more aggressively
    
Ridge retains all features but reduces coefficient magnitudes.


3.4 LASSO REGRESSION (L1 Regularization)
Lasso (Least Absolute Shrinkage and Selection Operator) uses an L1 penalty:

    Cost = RSS + α * Σ|βj|

Key property:
    - L1 penalty can force some coefficients exactly to zero.
    - This performs automatic feature selection.
    - Useful when many features are irrelevant or redundant.


3.5 EVALUATION METRICS

   R2 Score (Coefficient of Determination):
   Proportion of variance in y explained by the model.
       R2 = 1 - (SS_residual / SS_total)
   Range: 0 to 1. Closer to 1 means a better fit.

   MAE (Mean Absolute Error):
   Average of absolute differences between actual and predicted values.
       MAE = (1/n) * Σ|y - ŷ|
   Easier to interpret; less sensitive to large errors.

   MSE (Mean Squared Error):
   Average of squared differences. Penalizes large errors more heavily.
       MSE = (1/n) * Σ(y - ŷ)²

   RMSE (Root Mean Squared Error):
   Square root of MSE. Same unit as the target variable (dollars in this case).
       RMSE = √MSE
   Directly interpretable as average prediction error in dollars.


3.6 HAVERSINE FORMULA (Feature Engineering)
Pickup and drop-off coordinates by themselves are weakly correlated with fare
(R = ~0.0001). The actual trip distance, calculated using the Haversine formula,
is the most predictive feature (R = 0.72).

    a = sin²(Δlat/2) + cos(lat1) * cos(lat2) * sin²(Δlon/2)
    distance = 2 * R * arcsin(√a)

Where R = 6371 km (Earth's radius).

This feature engineering transforms the raw coordinates into a meaningful,
physically interpretable variable that dramatically improves model accuracy.


3.7 IQR METHOD FOR OUTLIER DETECTION
Outliers are identified using the Interquartile Range (IQR):
    IQR = Q3 - Q1
    Lower Limit = max(0, Q1 - 1.5 * IQR)
    Upper Limit = Q3 + 1.5 * IQR

Fare values outside [Lower, Upper] are removed as they represent corrupted
records or extremely unusual rides that would distort model training.

7. ANALYSIS & DISCUSSION
--------------------------------------------------------------------------------
1. Importance of Feature Engineering:
   Raw latitude and longitude coordinates had near-zero correlation (~0.001)
   with fare_amount. Computing the Haversine distance from pickup to drop-off
   produced a feature with correlation 0.72, dramatically improving model
   accuracy from R2 ≈ 0.02 to R2 ≈ 0.62.

2. Model Performance Comparison:
   - All three models (Linear, Ridge, Lasso) achieved similar performance
     because the dataset's predictive signal is predominantly linear (distance).
   - Linear Regression performed marginally best (R2 = 0.617, RMSE = $2.55).
   - Ridge Regression performed nearly identically to Linear Regression;
     the mild L2 penalty (α = 1.0) had negligible effect on this dataset.
   - Lasso Regression showed slightly lower R2 (0.611), as the L1 penalty
     zeroed out a few weakly predictive features (e.g., raw coordinates).
   - RMSE of ~$2.55 means predictions are within ±$2.55 of the actual fare
     on average, which is acceptable for this dataset's fare range ($0–$22).

3. Outlier Handling:
   The IQR method removed records with fares above $22.25, representing
   less than ~11% of data. This cleanup reduced the RMSE and improved model
   stability without significant information loss.

4. Limitations of Coordinate-Only Features:
   The remaining unexplained variance (R2 ≈ 0.38) arises from factors not
   captured by the current features: surge pricing, traffic conditions,
   tolls, and Uber service type (UberX vs. Uber Black).

8. VIVA-VOCE / ORAL EXAMINATION QUESTIONS & ANSWERS
--------------------------------------------------------------------------------
Q1. What is the difference between Ridge and Lasso Regression?
Ans: Both add regularization to prevent overfitting. Ridge uses L2 penalty
     (squares of coefficients), which shrinks all coefficients toward zero
     but retains all features. Lasso uses L1 penalty (absolute values), which
     can shrink some coefficients exactly to zero, performing feature selection.

Q2. Why is feature scaling necessary before applying regression?
Ans: Ridge and Lasso apply penalties based on coefficient magnitude. If features
     are on different scales (e.g., distance in km vs. hour 0-23), unscaled
     features will have larger coefficients and receive disproportionately large
     penalties. StandardScaler ensures equal treatment of all features.

Q3. Why is R2 not always a reliable metric alone?
Ans: R2 measures variance explained but does not indicate whether predictions
     are practically useful. A model can have a decent R2 yet have a high RMSE
     if the target variable has high variance. RMSE provides error in the same
     unit as the target (dollars), making it more interpretable.

Q4. What does an RMSE of $2.55 mean in this experiment?
Ans: On average, the model's predicted fare deviates from the actual fare by
     approximately $2.55. For rides priced between $4–$22, this represents a
     relative error of roughly 12–15%, which is moderate accuracy.

Q5. Why did raw GPS coordinates perform poorly as features?
Ans: Latitude and longitude coordinates alone do not capture trip distance. Two
     rides with very similar pickup coordinates could have vastly different
     drop-off locations and thus very different fares. The Haversine formula
     combines all four coordinates into a single, physically meaningful distance
     feature that directly relates to fare pricing.

Q6. What is the Haversine Formula and why is it used?
Ans: The Haversine formula computes the great-circle distance between two points
     on a sphere given their latitudes and longitudes. It accounts for Earth's
     curvature, making it more accurate than Euclidean distance for geographic
     calculations. This is the appropriate formula for computing trip distances
     from GPS coordinates.
