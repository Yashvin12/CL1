3. THEORETICAL BACKGROUND
--------------------------------------------------------------------------------
3.1 CLUSTERING
Clustering is an unsupervised machine learning technique that groups unlabeled
data points such that:
- Points within the same cluster are similar to each other.
- Points in different clusters are dissimilar.
Unlike classification, there are no predefined labels — the algorithm discovers
structure on its own.


3.2 K-MEANS CLUSTERING
K-Means partitions n data points into K non-overlapping clusters by minimizing
the Within-Cluster Sum of Squares (WCSS), also called Inertia:

    WCSS = Σ_k Σ_{x ∈ Ck} ||x − μk||²

Where:
    K  = Number of clusters
    Ck = Set of points in cluster k
    μk = Centroid (mean) of cluster k
    ||x − μk||² = Squared Euclidean distance from point x to centroid μk


3.3 K-MEANS ALGORITHM (Step-by-Step)
Step 1: Choose K — the number of clusters.
Step 2: Initialize K centroids randomly from the data points.
Step 3: Assignment Step — assign each data point to the nearest centroid:
            c(i) = argmin_k ||x(i) − μk||²
Step 4: Update Step — recalculate each centroid as the mean of all assigned points:
            μk = (1 / |Ck|) * Σ_{x ∈ Ck} x
Step 5: Repeat Steps 3–4 until centroids stop changing (convergence) or the
        maximum number of iterations is reached.

Simple Example (K=2):
Points: A(1,2), B(1,4), C(1,0), D(10,2), E(10,4), F(10,0)
Initial centroids: C1=(1,2), C2=(10,2)
After Step 3: Cluster 1 = {A,B,C}, Cluster 2 = {D,E,F}
After Step 4: C1=(1,2), C2=(10,2) — no change → Converged.


3.4 ELBOW METHOD
The Elbow Method is used to find the optimal K by plotting WCSS against K:
- As K increases, WCSS always decreases (more clusters = tighter groupings).
- The rate of decrease slows after the true K.
- The "elbow" — the point where the decrease rate sharply flattens — is the
  optimal number of clusters.

WCSS values for K = 1 to 10 (this experiment):
    K=1: 600.00    K=2: 222.36    K=3: 139.82    K=4: 114.09
    K=5:  90.93    K=6:  81.54    K=7:  72.63    K=8:  62.54
    K=9:  55.12    K=10: 47.39
The sharpest drop is between K=1→2 and K=2→3.
After K=3, the decrease becomes gradual → Elbow at K=3.


3.5 EUCLIDEAN DISTANCE
K-Means uses Euclidean distance to measure similarity between a point and centroid:

    d(x, μ) = √( Σ (xi − μi)² )

For 4 features (Iris): d = √((s₁-c₁)² + (s₂-c₂)² + (p₁-c₃)² + (p₂-c₄)²)


3.6 WHY STANDARDIZE BEFORE K-MEANS?
Features with larger numerical ranges dominate the distance calculation.
Iris features: sepal length (~4–8 cm) vs. petal width (~0.1–2.5 cm).
StandardScaler transforms each feature to zero mean and unit variance:
    z = (x − μ) / σ
This ensures all four features contribute equally to distance computation.


3.7 LIMITATIONS OF K-MEANS
- Requires K to be specified in advance.
- Sensitive to initial centroid positions (solved via n_init=10 — runs 10 times).
- Assumes spherical, equally-sized clusters.
- Sensitive to outliers (uses mean, not median).

8. VIVA QUESTIONS & ANSWERS
--------------------------------------------------------------------------------
Q1. What is the difference between supervised and unsupervised learning?
Ans: Supervised learning trains on labeled data (input + output pairs) to predict
     outputs for new inputs. Unsupervised learning finds hidden structure in
     unlabeled data. K-Means is unsupervised — it groups data without using labels.

Q2. What is WCSS / Inertia?
Ans: WCSS (Within-Cluster Sum of Squares) measures the total squared distances
     from each data point to its assigned cluster centroid. Lower WCSS means
     tighter, more compact clusters.

Q3. What is the Elbow Method?
Ans: A technique to determine the optimal K by plotting WCSS vs. K. As K increases,
     WCSS decreases. The "elbow" point — where the rate of decrease sharply slows —
     indicates the optimal K, beyond which adding clusters gives diminishing returns.

Q4. Why is n_init=10 used?
Ans: K-Means results depend on random initial centroids. Running n_init=10 means
     the algorithm runs 10 times with different initializations and keeps the best
     result (lowest WCSS), avoiding poor local minima.

Q5. What distance metric does K-Means use?
Ans: By default, K-Means uses Euclidean distance to measure how close a point is
     to each centroid: d = √Σ(xi − μi)². The point is assigned to the nearest centroid.

Q6. What are the limitations of K-Means?
Ans: (1) K must be specified in advance. (2) Sensitive to initial centroids.
     (3) Assumes spherical, equally-sized clusters. (4) Sensitive to outliers.
     (5) Not suitable for non-convex cluster shapes.
